# Z3-code

[Zeron](https://github.com/zeronsh/zeron)’s native UI + [T3 Code](https://github.com/pingdotgg/t3code)’s backend.

Linux x64. [Download](https://github.com/DerpcatMusic/z3-code/releases). Start T3, then run `z3-code`.

Build: `cd native/zeron && cargo build --release --locked -p zeron`.
Daily CI checks upstream compatibility. [Native notes](native/README.md). Original licenses retained.
